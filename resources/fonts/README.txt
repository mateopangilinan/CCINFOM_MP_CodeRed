Poppins Regular, Medium and SemiBold, unmodified Google Fonts distribution.
Source: https://github.com/google/fonts/tree/main/ofl/poppins
License: SIL Open Font License 1.1; see Poppins-OFL.txt.
Regular is used for body text, Medium for controls and emphasis, and SemiBold
for headings and login labels. Font files require no installation.
Only the active Poppins faces are shipped with this application.
